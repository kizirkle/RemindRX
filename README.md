# RemindRX
A course project that stores information about medication for users

Remember to create a ".env" file with: 
    MYSQL_HOST='127.0.0.1'
    MYSQL_USER='your user (probably root)'
    MYSQL_PASSWORD='your password'
    MYSQL_DATABASE='your databse name'

In MySQL, access one of your connections
    Type CREATE DATABASE RemindRx (or whatever you want to name your database)
    Type USE ReminderRx 
    Copy and paste from remindrx.sql
